# 비밀번호 로그인
- 로그인
  - 로그인 성공 [P0]
    - AC: 올바른 비밀번호를 입력하면 메인 화면으로 이동한다
  - 계정 잠금 [P0]
    - AC: 비밀번호를 5회 연속 틀리면 계정이 30분간 잠긴다
    - AC: 잠긴 계정으로 로그인하면 잠금 안내 문구를 노출한다
    - HINT: 4회 실패 후 성공하면 실패 횟수가 초기화된다
- 로그인 상태 유지
  - 상태 유지 선택 [P1]
    - AC: 로그인 상태 유지를 선택하면 앱을 다시 열어도 로그인이 유지된다
  - 로그아웃 [P1]
    - AC: 로그아웃하면 유지된 로그인 정보가 삭제된다
